# Bento Grid Generator

Design bento, Mondrian, masonry and other grid layouts and export them as SVG, PNG or PDF. Also available on the web at [bento.samolevsky.com](https://bento.samolevsky.com).

## Updating

The app checks for updates on launch. You can also choose **Bento Grid Generator › Check for Updates…** on macOS or **Help › Check for Updates…** on Windows. Updates are signed and verified, and install when you restart the app or quit after choosing **Later**.

**Upgrading from Electron:** the old Electron installers and update feeds are retired. Install the matching Tauri DMG or EXE once. Keep your previous user profile; the new app imports your settings and license on first launch. Subsequent releases use Tauri's Check for Updates feature.
