# Bento Grid Generator

Design bento, Mondrian, masonry and other grid layouts and export them as SVG, PNG or PDF. Also available on the web at [bento.samolevsky.com](https://bento.samolevsky.com).

## Download

Get the latest version from the [Releases page](https://github.com/Samolevsky/Bento-Grid-Generator-Releases/releases/latest):

| Platform | File |
| --- | --- |
| macOS — Apple Silicon (M1 and later) | `Bento-Grid-Generator-<version>-mac-arm64.dmg` |
| macOS — Intel | `Bento-Grid-Generator-<version>-mac-intel.dmg` |
| Windows 10/11 (64-bit) | `Bento-Grid-Generator-<version>-win-x64.exe` |

The Windows installer isn't code-signed yet; if SmartScreen warns, choose **More info › Run anyway**.

## Updating

The app checks for updates on launch. You can also choose **Bento Grid Generator › Check for Updates…** on macOS or **Help › Check for Updates…** on Windows. Updates install when you restart the app.
